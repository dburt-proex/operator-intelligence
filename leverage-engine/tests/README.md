# Advisory MVP Test Contract

**Version:** 0.1.0  
**Stage:** Acceptance gate  
**Folder alignment:** `leverage-engine/tests/`

The test suite proves deterministic selection, canonical schema validation, locked profile weights, unknown-data handling, duplicate preservation and suppression, stale-snapshot invalidation, unconditional G4 HALT behavior, injection containment, urgency evidence, ledger idempotency, explicit realized-value state, and the absence of network/process execution imports.

Run with `PYTHONPATH=src python -m unittest discover -s tests -v`. A zero exit code and the five expected fixture outcomes are required completion evidence. Test success does not authorize Phase 2 live adapters, Phase 5 dispatch, or Phase 6 automation.
