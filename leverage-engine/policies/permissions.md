# MVP Permissions

**Version:** 0.1.0  
**Stage:** Advisory MVP  
**Folder alignment:** `leverage-engine/policies/`

Allowed capabilities are static file reads, deterministic computation, local output writes, idempotent local ledger append, and draft directive presentation.

Denied capabilities are network access, repository mutation, PR publication, messages, applications, purchases, financial actions, secret collection, sensitive-data ingestion, agent dispatch, and self-modification. A future adapter must be separately approved and cannot inherit authority from this document.
